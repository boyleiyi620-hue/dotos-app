# DostOS 🎯

**Planla, Paylaş, Yaşa.**

Arkadaş grubu yönetim uygulaması — aktivite planla, borç takip et, turnuva düzenle, anıları paylaş.

## 🌐 Canlı Uygulama

👉 **[DostOS'u Aç](https://boyleiyi620-hue.github.io/dotos-app/)**

## 📱 Ana Ekrana Ekle (PWA)

### Android (Chrome)
1. Uygulamayı Chrome'da aç
2. Sağ üst menüden **"Ana ekrana ekle"** seçeneğine bas
3. Uygulama gibi çalışır!

### iPhone/iPad (Safari)
1. Uygulamayı Safari'de aç
2. Alt menüdeki **Paylaş** ikonuna bas
3. **"Ana Ekrana Ekle"** seçeneğini seç

## ✨ Özellikler

- 🧭 **Keşfet** — Aktivite öner, oyla, arkadaşlarının önerilerini gör
- 🏆 **Arena** — Lig kur, meydan oku, lider panosu
- 💰 **Kasa** — Grup cüzdanı, borç takibi, abonelikler
- 🔥 **Atölye** — Mangal, proje panosu, ekipman takibi
- ⚡ **Canlı** — Akış, albüm, müzik kuyruğu, oyun gecesi
